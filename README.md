# CALAS Programme Dashboard

A self-hosted dashboard that automatically scrapes all programmes from the
[SILE CALAS listing](https://www.silecpdcentre.sg/calas/), stores them in a
static `events.json` file, and serves a filterable HTML table via GitHub Pages.

## Features

- Lists every programme with title, date, organiser, practice area, training level, MEC segment, and points (MEC or CPD)
- Filters: date range, points type (MEC / CPD), format, free-text search
- Sortable by date, points, or title
- Paginated (50 per page)
- Auto-refreshes daily via GitHub Actions (no server needed)

## Quick start (local)

```bash
# 1. Clone
git clone https://github.com/YOUR_USERNAME/calas-dashboard.git
cd medhustle

# 2. Install deps
pip install -r requirements.txt

# 3. Run scraper (writes events.json)
python scrper.py

# 4. Preview locally
npm start          # serves on http://localhost:8080
# or just open index.html directly in a browser
```

## Deploy to GitHub Pages

### Step 1 — Create the repo

Create a **new public repo** on GitHub named `calas-dashboard`.

```bash
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/calas-dashboard.git
git push -u origin main
```

### Step 2 — Enable GitHub Pages

1. Go to your repo → **Settings** → **Pages**
2. Under *Build and deployment*, set **Source** to **GitHub Actions**
3. Save

### Step 3 — Trigger the first scrape

1. Go to **Actions** tab in your repo
2. Select **Scrape CALAS & Deploy**
3. Click **Run workflow** → **Run workflow**

The action will:
1. Scrape all event detail pages
2. Commit `events.json` to `main`
3. Deploy the updated site to GitHub Pages

Your dashboard will be live at:
```
https://YOUR_USERNAME.github.io/mechustle
```

### Step 4 — Automatic daily refresh

The workflow runs automatically every day at **08:00 SGT** (00:00 UTC).
You can also trigger it manually any time from the Actions tab.

## Customise the schedule

Edit `.github/workflows/scrape-and-deploy.yml`:

```yaml
schedule:
  - cron: "0 0 * * *"   # daily at 07:00 SGT
```

[Cron syntax reference](https://crontab.guru/)

## Troubleshooting

| Problem | Fix |
|---|---|
| `events.json` is empty | Run the scraper manually: `python scraper.py` |
| GitHub Action fails | Check the Actions log; SILE may be temporarily down |
| Dashboard shows stale data | Trigger the workflow manually from Actions tab |
| Scraper gets rate-limited | Increase `DELAY_MS` in `scripts/scraper.py` (currently 600ms) |
